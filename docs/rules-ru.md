# Правила русского языка, которые клавиатура решает по контексту

Сводный список двух обзоров:
- **по школьной программе** — Розенталь, правила 2006 года;
- **по ошибкам реального набора** — Тотальный диктант 2025, ЕГЭ 2024, SpellRuEval, замеры по корпусам Leipzig: веб 2019 и новости 2022, по 1 млн предложений.

В список попадают только правила, где контекст решает, какую из двух законных форм взять, где нужен знак препинания или где писать слитно или раздельно. Орфографию отдельного слова (безударные гласные, жи/ши, чередования) закрывает словарь: в нём только правильные формы.

Как читать:
- **окно** — какие слова решают: `−1` — предыдущее, `+1` — следующее, «клауза» — часть сложного предложения;
- **учится** — можно ли выучить правило по корпусу (пары слов, грамматические теги): да, частично или трудно;
- **веб X%** — доля ошибочного варианта в том же контексте. Это порядок величины, в чатах доля, скорее всего, выше.

Главная оговорка про обучение. Веб систематически ошибается ровно в этих правилах: «в течении», «не смотря на», «тем не менее,», «подскажите пожалуйста». Учить их надо на вычитанных текстах (новости, книги) или задавать закрытым списком, иначе модель выучит ошибку.

## Сделано

| правило | как | где |
|---|---|---|
| Согласование прилагательного с существительным | разборы всех форм, выученные веса, у частых прилагательных свой штраф («всем друг», «всем привет») | `gram.rs`, `frames.tsv` (`@attr`, `*слово`) |
| Падеж после предлога | рамка предлога; уточняется по глаголу, к которому он относится («бежала за велосипедом», «заплатила за велосипед»), и по слову перед ним («что за», «благодарю за») | `&класс предлог`, `^слово предлог` |
| Подлежащее и сказуемое | через наречия; краткие прилагательные и причастия; однородные подлежащие («Эстелла и я идём»); кто, никто, ничто; что идёт после подлежащего по видам слов | `@attr`, `@subj`, `@subjx` |
| Безличное после родительного с «не» | «её не существовало»; вес пока общий | `@impers` |
| Управление глаголов | рамки: инфинитив после модальных; стек ожиданий — рамка клаузы («дал книгу другу») | `frames.tsv`, `%глагол` |
| После «X и» падеж X | «кошку и собаку» | `@coord` |
| Числительные 2–4 и прилагательное | «два больших стола», «две большие книги» | `Walk::paucal` |
| -тся / -ться | своя цена ошибки (`c_tsya`), рамки, подлежащее | `engine.rs`, `config.rs` |
| тоже/то же, также/так же, чтобы/что бы | пары-путаницы, правила по следующему слову | `confusions.tsv`, `rules.tsv` |
| к/ко, с/со, в/во, о/об/обо, не/ни | правописные пары по следующему слову; «о» → «об» перед гласной по звуку | те же + `next_evidence` |
| н/нн | пары по следующему слову (осторожно: партнёры только от промаха) | `confusions.tsv` |
| Дефисы: кто-то, что-либо, кое-что, по-русски, во-первых | склейка через дефис, если слово есть в словаре и вероятнее двух | `ime.rs`, `find_hyphen` |
| Ё, где е и ё одно слово | «еще» → «ещё», «пошел» → «пошёл», настройка «Ё» | `Engine::yo_form` |
| Запятые перед что, который, но, а, вводные слова | шансы по словам и парам | `commas.tsv` |
| Запятые при оборотах | открытие перед деепричастием и причастием (по тому, что перед ним), закрытие перед сказуемым открытого оборота; «и…, и…»; обращение в начале; однородные в одном падеже | `commas.tsv` (`#…`), `engine/commas.rs` |
| Заглавные в начале предложения и в именах | | `casing.fst` |

Замер `tools/eval_rules.py --n 300`. Берутся отложенные предложения Tatoeba, в каждое вносится одна ошибка своего вида, набор идёт с шумом нажатий. «Исправлено» — предложение вышло верным. «Тронуто» — сколько верно набранных слов клавиатура изменила. 30 сентября 2026 (в скобках — 29 сентября):

| вид | исправлено | тронуто верных слов |
|---|---|---|
| -тся / -ться | 78,3% (74,3%) | 1,6% (из них ~20 слов — одно предложение с дореформенным «естьли», сдвиг выравнивания) |
| дефисы | 97,7% (95,3%) | 0% |
| ё | 99,1% | 0,2% |
| в/во, с/со, о/об, к/ко | 83,3% (63,0%) | 0,2% |
| н/нн | 3% | 0,4% |
| согласование | 65,2% (63,3%); 79,7% с подлежащим из графа (`graph_subject=1`, пока выключено) | 0,3% |
| запятые | 28,4% | 0,1% запятых не на месте |

Предлоги: окно из двух слов пропускало пару («со» к «с»), если поиск уже нашёл её сам как опечатку («пропущена буква») — пара оставалась с ценой опечатки, а не своей. Исправлено 30 сентября: 59 → 83%.

## По приоритету: что делать дальше

1. **Запятая после «Да / Нет / Блин / Короче / Слушай / Кстати / Ладно / Спасибо» в начале реплики.** В чатах, вероятно, случай №1. Веб: «Короче…» без запятой 44%, «Да…» около 42%, «Блин» 30%.
   - Окно: начало предложения + слово + `+1`.
   - Без запятой: «Да и», «Да ладно», «Да ну», «Да уж», «Да здравствует», «Нет денег» («нет» здесь сказуемое).
   - Учится: да, если добавить признак начала предложения для самих слов (для видов слов он уже есть).
2. **«Пожалуйста» в запятых.** Веб 51% без запятой, новости 40%. Модель запятых выучила эту ошибку: «подскажите пожалуйста» даёт p ≈ 0,46. Лечится данными (новости, книги) или правилом. Риск почти нулевой. Не выделяется в «Пожалуйста!» и в «скажите пожалуйста!» (возмущение).
3. **Запятая перед если / когда / чтобы / пока / хотя / как / где / почему / ли**, после глаголов речи и мысли и после «хочу / надо».
   - Веб: без запятой «если» 11%, «когда» 8%, косвенный вопрос после «знаю / понимаю / скажи» 29%.
   - Окно: `−1` + союз + `+1`.
   - Без запятой: придаточное из одного слова («Не знаю почему.»); как раз, как можно, когда угодно, что попало; стык союзов «что если».
   - Закрывающая запятая — трудно, нужен счётчик клауз.
4. **Слитно или раздельно: производные предлоги и наречия против «предлог + слово».** Окно `−1`/`+1`, веб 7–50%:
   - в течение / в течении (+1: время), вследствие, в виду / ввиду;
   - иметь в виду (−1…−3: «иметь»);
   - несмотря на / не смотря (+1: на то / это);
   - насчёт / на счёт (перевести на счёт);
   - при чём тут (52%!), и так понятно / итак;
   - насколько / на сколько (+1: дней / процентов);
   - навстречу / на встречу (+1: с / выпускников);
   - в начале / вначале, сначала / с начала, наконец / на конец (+1: родительный падеж);
   - поэтому / по этому (+1: поводу), зато / за то (что).

   Нужен тип набора «одно слово ↔ два», склейки и разбиения у нас уже есть. Если справа ничего нет, оба варианта законны, и тогда ничего не менять.
5. **«Не» слитно или раздельно с прилагательными, наречиями на -о, словами состояния.** По Тотальному диктанту и ЕГЭ — самая частая орфографическая трудность (68%). Веб: «не понятно» 31%, «не правильно» 15%.
   - По умолчанию слитно.
   - Раздельно — при усилителях отрицания слева (далеко не, вовсе не, отнюдь не, ничуть не) и при противопоставлении «, а …» справа (до шести слов).
   - Полное причастие: с зависимыми словами раздельно, без них слитно.
   - Риск: намеренное «мне НЕ понятно». Начать с безопасного подмножества.
6. **Числа цифрами.** Около 2 тыс. на млн предложений веба.
   - Наращения: у количественных числительных нет («в 2 экземплярах»); у порядковых по форме слова («5-й, 5-го, 5-му»); «5-этажный», «25-летний».
   - Форма существительного: 1 (кроме 11) — ед. ч.; 2–4 (кроме 12–14) — род. п. ед. ч.; остальное — род. п. мн. ч.; дробь — род. п. ед. ч.
   - Даты без наращения («с 1 по 5 мая»), номера моделей не трогать.
   - Учится: да, если нормализовать числа в классы.
7. **«Пол» + существительное.** Веб 10%.
   - Слитно по умолчанию («полчаса»).
   - Через дефис перед гласной, «л» и заглавной («пол-литра», «пол-Москвы»).
   - Раздельно при определении («пол чайной ложки»); в косвенных падежах «полу-» («около получаса»).
   - Риск: «пол» как поверхность («помыть пол кухни»).
8. **Дефисы:**
   - всё-таки (12%), -ка («давай-ка», 16%);
   - по-моему / по-другому (10–19%) — но «по моему мнению», «по другому пути» раздельно;
   - повтор «очень-очень» (18%);
   - кое- с предлогом внутри раздельно («кое с кем»);
   - ложные дефисы убирать: как будто, то есть, так что, всё равно, вряд ли, что ли.
9. **«По» + предложный падеж в значении «после»:** по окончании, приезде, прибытии, истечении, возвращении, завершении, получении. Ошибаются 31% веба и 27% новостей. Наша рамка «по → дательный» толкает к ошибке. Нужен закрытый список.
10. **-ите / -ете:** повелительное наклонение против будущего времени («Когда вы напишете», «Напишите мне»). После «если / когда / вы» → «-ете». ЕГЭ 35%. Это однословные пары, ложатся в `confusions.tsv`. Автоматически исправлять только после союза.
11. **Прошедшее время после «бы» и «чтобы»:** «чтобы он пришёл», а не «придёт».
12. **«у него», но «у его брата»:** н- после предлога, кроме притяжательного.
13. **«который» по роду и числу:** согласуется с тем, к чему относится, а не со сказуемым.
14. **нечего / ничего, некогда / никогда, негде / нигде, некого / никого:**
    - «ни-» — если в клаузе есть «не» при сказуемом;
    - «не-» — в безличном предложении с инфинитивом («мне нечего делать»);
    - осторожно: «некогда процветавший», «Ничего!».
15. **Лишние запятые:** «Но,», «Поэтому,», «Однако,» в начале (союз), «Тем не менее,» (не вводное, веб 71%!), «как бы», «типа». Главное — клавиатура не должна ставить такие запятые сама. Убирать набранное — только подсказкой.
16. **Заглавная не на месте:** после сокращений (т. е., т. к., и т. д., г., ул., руб.) и в прямой речи после «?» или «!» + «—».
17. **Праздники и даты:** «С Новым годом», «с днём рождения», «8 Марта» (праздник); месяцы и дни недели со строчной. Веб 22–33%.
18. **Составные слова:**
    - онлайн-курс, бизнес-план, интернет-магазин, топ-менеджер — через дефис, веб 22%;
    - фотосессия, видеозвонок, авто-, эко- — слитно;
    - «фото кота» раздельно.
19. **н/нн в кратких формах:** «я уверена» (веб 13% «уверенна»), «стена покрашена». Решает подлежащее слева и зависимое слово.
20. **обоих / обеих, полтора / полторы:** по роду существительного справа, в том числе через прилагательные. Веб 5%.
21. **одеть / надеть:** «надеть что», «одеть кого». Веб 29%. Только подсказкой: «одеть куртку» многие считают нормой.
22. **«Вы» с прописной:** со строчной при обращении к нескольким («вам всем»); для одного — выбор автора. Только настройкой.

## Дальше по разделам

Для справки, приоритет ниже.
- **Орфография:**
  - не с причастиями и словами категории состояния;
  - недо- / не до-;
  - не кто иной / никто иной;
  - частицы -то, -таки, -де;
  - ь после шипящих («плач / плачь», «туш / тушь»);
  - о / ё после шипящих («ожог / ожёг»);
  - омофоны;
  - дефис при приложении;
  - повторы через дефис или запятую.
- **Морфология:**
  - собирательные числительные;
  - склонение составных числительных;
  - родительный множественного после слов количества;
  - степени сравнения;
  - вид глагола по контексту;
  - формы множественного числа;
  - склонение фамилий по полу;
  - род несклоняемых слов;
  - названия при родовом слове.
- **Синтаксис:**
  - управление существительных и прилагательных;
  - однородные члены с разным управлением;
  - деепричастный оборот при другом субъекте;
  - смешение оборотов.
- **Лексика:** паронимы, плеоназмы, фразеологизмы с ловушками — только подсказки.
- **Пунктуация:**
  - составные союзы (где запятая);
  - два союза подряд;
  - однородные придаточные без запятой перед «и»;
  - двойные союзы;
  - устойчивые выражения с повторяющимися союзами;
  - сложносочинённые при других союзах;
  - обобщающие слова;
  - обособленные определения и приложения;
  - обороты с производными предлогами;
  - уточнения;
  - междометия, «да», «нет», «пожалуйста»;
  - тире в неполном предложении;
  - бессоюзные сложные предложения (запятая, двоеточие или тире — только подсказкой);
  - прямая речь;
  - знак вопроса;
  - кавычки в названиях.
- **Типографика (настройка):** «ёлочки», тире «—», многоточие «…».

## Что нужно движку сверх нынешнего

1. **Признак начала предложения для отдельных слов** в модели запятых. Для видов слов он уже есть: `#^`.
2. **Вычитанные тексты для обучения:** Leipzig news, книги, основной корпус НКРЯ. Вместо веба или вместе с ним — для запятых, пар-путаниц и слитно/раздельно. Где ошибается и корпус («по окончании», «тем не менее»), нужны закрытые списки.
3. **Тип набора «одно слово ↔ два»** для всех пар слитно/раздельно. Сейчас он есть для склеек, разбиений и дефисов.
4. **Правый контекст дальше `+1` и конечный знак** — для противопоставления «а», закрывающей запятой, «ли». Это перечитывание уже набранного слова, как в окне из двух слов.
5. **Классы чисел** (1 / 2–4 / 5+ / 11–14 / дробь / год).
6. **Счётчик клауз.** Грамматическая основа в каждой части сложного предложения нужна для запятых между клаузами.
7. **Закрытые списки:** праздники, сокращения, существительные после «по», элементы составных слов, усилители отрицания.

## Найдено на примерах

«Отец бил сына потому что он был пьян», 30 сентября 2026:

1. **Запятая перед «потому что»** не ставится. Это пункт 3 списка (запятые перед подчинительными союзами).
2. **Составное сказуемое:** «она была пьян» — связка согласуется с подлежащим, краткое прилагательное после неё нет. Грамматика должна вести подлежащее через связку («был/была/было») до именной части.
3. **Слово, оставленное без исправления, не пересматривается по следующему.** «мать юила сына»: кандидаты «была / жила / била» близки, клавиатура не тронула набранное. «сына» в винительном решило бы в пользу «била», но окно из двух слов пересматривает только исправленные или набранные словарные слова.
